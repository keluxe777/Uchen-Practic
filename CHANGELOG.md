# История версий

## 1.2 — новый интерфейс, исправлено распознавание песен

- Новый интерфейс: тема в стиле Windows 11 (sv-ttk), панель действий слева, карточка файла сверху, тёмная тема (выбор запоминается), подсказки в пустых таблицах, чёткий шрифт на экранах с масштабом 125–150%.
- **D-06** — русская песня определялась как греческий язык: язык определялся только по первым 30 секундам, а в песне это вступление. Теперь язык определяется по 4 отрезкам записи с голосом, и вместо кода («el») показывается название.
- **D-07** — на песне с музыкой расшифровывались только последние секунды: модель отбрасывала «неуверенные» фрагменты. Теперь их оставляет, а тишину отсекает фильтр голоса. Добавлен автотест, что в тишине текст не выдумывается.
- Добавлен украинский язык.

## 1.1 — исправленная версия

Исправлены дефекты, найденные при тестировании (подробно — в `docs/3_Тестирование.docx`):

- **D-01** — Ctrl+O, Ctrl+P, Ctrl+S не работали при русской раскладке. Теперь клавиши определяются по коду, а не по букве.
- **D-02** — кнопки «Расшифровать» и «Отмена» пропадали из узкого окна. Настройки и запуск перенесены во вторую строку.
- **D-03** — панель экспорта и статистика не были видны при стандартном размере окна. Панель закреплена внизу.
- **D-04** — при минимальном размере окна обрезались кнопки поиска и правки. Кнопки переставлены.
- **D-05** — обрезалась надпись «Определить автоматически». Поле расширено.

Добавлено: сборка в exe (`build.bat`) с иконкой. Модель лежит рядом с exe в папке `models`, история — в папке `data` рядом с exe. Ещё добавлены сценарная проверка окна `tools/gui_check.py`, скриншоты, документация, тестовые файлы в `samples/test_data/`.

- Автотесты логики и распознавания.
