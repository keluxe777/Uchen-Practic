# История версий

## 1.1 — исправленная версия

Исправлены дефекты, найденные при тестировании (подробно — в `docs/3_Тестирование.docx`):

- **D-01** — Ctrl+O, Ctrl+P, Ctrl+S не работали при русской раскладке. Теперь клавиши определяются по коду, а не по букве.
- **D-02** — кнопки «Расшифровать» и «Отмена» пропадали из узкого окна. Настройки и запуск перенесены во вторую строку.
- **D-03** — панель экспорта и статистика не были видны при стандартном размере окна. Панель закреплена внизу.
- **D-04** — при минимальном размере окна обрезались кнопки поиска и правки. Кнопки переставлены.
- **D-05** — обрезалась надпись «Определить автоматически». Поле расширено.

Добавлено: сценарная проверка окна `tools/gui_check.py`, скриншоты, документация, тестовые файлы в `samples/test_data/`.
