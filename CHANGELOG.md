# История версий

## Не выпущено

- Добавлена модель **large-v3-turbo** (~1,6 ГБ) — самая точная из доступных: расставляет знаки препинания и реже ошибается в словах. На i5-6300U запись 2:10 (`samples/sample_ru.mp3`) расшифровывается за ~4 мин (small — 47 с). Скачивается при первом выборе, потом загружается за ~7 с.
- Тема как в системе: новый переключатель «Тема как в системе» (включён по умолчанию) — программа светлая или тёмная так же, как приложения Windows, и сама меняется, если сменить тему в Windows во время работы. Ручной выбор «Тёмная тема» остался и запоминается. Добавлены 4 автотеста и 6 сценарных проверок окна.

## 1.3 — несколько языков в одной записи

Найдено при проверке на настоящей русской записи в MP3 (`samples/sample_ru.mp3`, подробно — в `docs/3_Тестирование.docx`, ТК-18):

- **D-09** — запись с двумя языками расшифровывалась на одном: 13 с английского вступления перед русской речью модель base записала как «Это либри вакс рекорд…», и почти всё вступление пропало. Теперь язык определяется для каждого отрезка речи между паузами, участки с другим языком расшифровываются отдельно, а в строке состояния видно «есть фрагменты: английский». Ошибок в словах на всей записи: base 41% → 31%, tiny 51% → 39%; расшифровка дольше на 15–25%.
- **D-08** — конец последнего фрагмента мог выходить за конец записи (tiny: 2:10,6 при длине 2:09,8), и в SRT попадало время, которого в записи нет. Теперь время ограничено длиной записи.
- Ручная установка (`pip install` в README и `build.bat`) падала на Python 3.12: для `av` 14.3–14.4 нет готовой сборки под Windows. Добавлен флаг `--only-binary=av`, как в `install.bat`.
- Добавлены `samples/sample_ru.mp3`, 14 автотестов и 3 сценарные проверки окна.

## 1.2 — новый интерфейс, исправлено распознавание песен

- Новый интерфейс: тема в стиле Windows 11 (sv-ttk), панель действий слева, карточка файла сверху, тёмная тема (выбор запоминается), подсказки в пустых таблицах, чёткий шрифт на экранах с масштабом 125–150%.
- **D-06** — русская песня определялась как греческий язык: язык определялся только по первым 30 секундам, а в песне это вступление. Теперь язык определяется по 4 отрезкам записи с голосом, и вместо кода («el») показывается название.
- **D-07** — на песне с музыкой расшифровывались только последние секунды: модель отбрасывала «неуверенные» фрагменты. Теперь их оставляет, а тишину отсекает фильтр голоса. Добавлен автотест, что в тишине текст не выдумывается.
- Добавлен украинский язык.

## 1.1 — исправленная версия

Исправлены дефекты, найденные при тестировании (подробно — в `docs/3_Тестирование.docx`):

- **D-01** — Ctrl+O, Ctrl+P, Ctrl+S не работали при русской раскладке. Теперь клавиши определяются по коду, а не по букве.
- **D-02** — кнопки «Расшифровать» и «Отмена» пропадали из узкого окна. Настройки и запуск перенесены во вторую строку.
- **D-03** — панель экспорта и статистика не были видны при стандартном размере окна. Панель закреплена внизу.
- **D-04** — при минимальном размере окна обрезались кнопки поиска и правки. Кнопки переставлены.
- **D-05** — обрезалась надпись «Определить автоматически». Поле расширено.

Добавлено: сборка в exe (`build.bat`) с иконкой. Модель лежит рядом с exe в папке `models`, история — в папке `data` рядом с exe. Ещё добавлены сценарная проверка окна `tools/gui_check.py`, скриншоты, документация, тестовые файлы в `samples/test_data/`.
