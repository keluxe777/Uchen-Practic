# Расшифровщик аудио

Учебная практика «Пиксель и Код» (36 часов), тема №12 «Расшифровщик аудио». Работа в паре.

Программа для Windows превращает аудиозапись в текст с таймкодами. Распознавание делает готовая модель
**Whisper** (библиотека faster-whisper) прямо на компьютере, запись никуда не отправляется. Результат можно
исправить и сохранить в TXT, SRT (субтитры) или Word.

![Главное окно](docs/screenshots/03_transcribed.png)

## Функции (7)

1. **Открытие аудиофайла с проверкой**: WAV, MP3, M4A, OGG, FLAC и др. Показывает формат, длительность и размер; отклоняет пустые, повреждённые и неподходящие файлы.
2. **Расшифровка речи**: выбор модели (tiny / base / small / large-v3-turbo) и языка (авто / русский / английский / украинский), шкала прогресса, отмена. Если в записи звучат разные языки (например, английское вступление перед русской речью), каждый участок расшифровывается на своём языке.
3. **Таймкоды**: таблица фрагментов со временем, переключатель «Показывать таймкоды».
4. **Редактирование**: правка фрагмента двойным щелчком, удаление фрагментов.
5. **Поиск и замена**: подсветка найденного, «Заменить всё».
6. **Экспорт**: TXT, SRT, DOCX.
7. **Проекты и история**: сохранить работу и продолжить позже; список прошлых расшифровок.

## Скачать

На странице [Releases](https://github.com/keluxe777/Uchen-Practic/releases) четыре варианта. Во всех, кроме исходного кода, Python и интернет не нужны: модель base уже внутри.

| Файл | Что это |
|---|---|
| `audio-transcriber-<версия>-setup.exe` | **Установщик** — рекомендуется. Ярлыки в меню «Пуск» и на рабочем столе, удаление через «Параметры → Приложения». |
| `audio-transcriber-<версия>-portable.zip` | Программа без установки: распакуйте и запустите `Расшифровщик аудио.exe` в папке. Можно носить на флешке. |
| `audio-transcriber-<версия>.exe` | Вся программа одним файлом: скачал и запустил. Открывается дольше остальных — при каждом запуске распаковывается во временную папку. |
| Source code (zip / tar.gz) | Исходный код, см. «Запуск из исходников». |

Windows может показать «Система Windows защитила ваш компьютер»: файлы не подписаны цифровой подписью. Нажмите «Подробнее» → «Выполнить в любом случае».

## Установка

Запустите `audio-transcriber-<версия>-setup.exe`. Установщик спросит:

1. Для кого установить: только для вас (права администратора не нужны) или для всех пользователей.
2. Папку установки (по умолчанию `%LOCALAPPDATA%\Programs\Расшифровщик аудио` или `Program Files`).
3. Папку в меню «Пуск» (можно не создавать).
4. Создать ли значок на рабочем столе.

Удаление — «Параметры → Приложения» или ярлык «Деинсталлировать Расшифровщик аудио» в меню «Пуск».

История и настройки хранятся в папке программы (`data`), а если в неё писать нельзя (установка в `Program Files`) — в `%LOCALAPPDATA%\Расшифровщик аудио`. Туда же скачиваются другие модели. Exe одним файлом всегда хранит их в `%LOCALAPPDATA%\Расшифровщик аудио`, чтобы не создавать папок рядом с собой.

## Запуск из исходников

Нужны Windows 10/11 и Python 3.10 или новее. При первой расшифровке нужен интернет: модель скачивается один раз.

1. `install.bat` — установить библиотеки (один раз).
2. `run.bat` — запустить программу.

Вручную:

```bash
pip install --only-binary=av -r requirements.txt
python main.py
```

## Сборка

`build.bat` собирает программу (PyInstaller), установщик (Inno Setup 6) и файлы для релиза. Нужно:

```bash
pip install --only-binary=av -r requirements.txt pyinstaller pillow
```

```bash
choco install innosetup
```

Результат — в папке `dist\release`: установщик, zip-архив и exe одним файлом (см. «Скачать»). Сценарий установщика — `installer.iss`, сборка файлов релиза — `tools/make_release.py`.

## Тесты

```bash
python -m unittest discover -s tests -t .
```

```bash
python tools/gui_check.py
```

- `tests/` — 62 автотеста логики и распознавания.
- `tools/gui_check.py` — 39 сценарных проверок окна программы.
- 18 ручных тест-кейсов и журнал дефектов — в `docs/3_Тестирование.docx`.
- `samples/sample_ru.mp3` — глава «Ивины» из «Детства» Л. Н. Толстого в чтении LibriVox (общественное достояние, Wikimedia Commons): 13 с английского вступления и русская речь.

Для скриптов из `tools/` (скриншоты, документы) нужен Pillow: `pip install -r requirements-dev.txt`.

## Структура

```
main.py               запуск программы
app/gui.py            окно (Tkinter)
app/transcriber.py    распознавание речи (faster-whisper)
app/audio_utils.py    проверка аудиофайла
app/exporter.py       экспорт TXT/SRT/DOCX, файлы проектов
app/text_tools.py     поиск, замена, статистика
app/theme.py          тема оформления: как в Windows, светлая, тёмная
app/history.py        история расшифровок
app/models.py         фрагмент, проект, формат времени
app/paths.py          где хранить историю, настройки и модели
build.bat             сборка программы и установщика
installer.iss         сценарий установщика (Inno Setup)
tests/                автотесты
tools/                проверка окна, скриншоты, генерация документов
samples/              тестовая запись и файлы для проверки ошибок
docs/                 карточка проекта, руководство, тестирование, скриншоты
```
